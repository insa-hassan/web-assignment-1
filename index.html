Welcome insa Internet & Web Fundamentals

The Internet and World Wide Web are important parts of modern technology and communication.

This page explains important Internet and Web concepts in a simple and easy way.

Learn the basic concepts of the Internet and Web below.

1. The Internet

The Internet is a global network that connects millions of computers and devices around the world. It allows people to communicate, share information and use different online services.

Some common uses of the Internet are:

  • Communication
  • Education
  • Online Shopping
  • Entertainment
  • Information Sharing

2. The World Wide Web (Web)

The World Wide Web, commonly called the Web, is a system of interconnected web pages and resources that can be accessed through the Internet.

Web pages are viewed using a web browser.

3. W3C - World Wide Web Consortium

W3C stands for World Wide Web Consortium. It is an international organization that develops standards and guidelines for the Web.

Website: https://www.w3.org/

4. Web Page

A web page is a document available on the World Wide Web. It is usually created using HTML and can contain text, images, links, videos and other elements.

5. Website

A website is a collection of related web pages that are available under a common domain name.

Examples of websites include educational, business, social media and news websites.

6. Home Page

The Home Page is the main or starting page of a website. It usually provides links to different sections and pages of the website.

7. Index Page

An Index Page is commonly used as the main entry page of a website. The file is often named index.html.

8. Landing Page

A Landing Page is a web page designed for visitors to reach after clicking a link, advertisement or search result.

9. Web Browser

A Web Browser is software used to access and view websites on the Internet.

Examples of web browsers are:

  1. Google Chrome
  2. Mozilla Firefox
  3. Microsoft Edge
  4. Safari

10. Web Server

A Web Server is a computer system or software that stores and delivers web pages and other resources to users through the Internet.

11. Web Domain

A Web Domain is the unique name used to identify a website on the Internet.

For example: google.com

12. URL - Uniform Resource Locator

URL stands for Uniform Resource Locator. It is the address used to locate a resource on the Web.

Example: https://www.example.com

13. URI - Uniform Resource Identifier

URI stands for Uniform Resource Identifier. It identifies a particular resource on the Internet or Web.

14. HTTP - HyperText Transfer Protocol

HTTP stands for HyperText Transfer Protocol. It is a protocol used for communication between web browsers and web servers.

HTTP is commonly used to request and transfer web resources.

15. HTTPS - HyperText Transfer Protocol Secure

HTTPS stands for HyperText Transfer Protocol Secure. It provides a more secure connection between a browser and a web server.

HTTPS is commonly used on websites where secure communication is important.

16. SSL - Secure Sockets Layer

SSL stands for Secure Sockets Layer. It is a security technology designed to help protect information sent between a browser and a server.

17. TLS - Transport Layer Security

TLS stands for Transport Layer Security. It is a security protocol used to provide privacy and data security when communicating over a network.

18. HTML - HyperText Markup Language

HTML stands for HyperText Markup Language. It is the standard markup language used to create the structure of web pages.

HTML can be used to create:

  • Headings
  • Paragraphs
  • Images
  • Links
  • Lists
  • Tables

19. IP Address

An IP Address is a numerical address used to identify a device on a network.

IP addresses help devices communicate with each other over a network.

Visit Google Search

23. ChatGPT

ChatGPT is an AI-based conversational tool that can understand user questions and generate responses in natural language.

It can be used for learning, writing, brainstorming, explaining concepts and many other tasks.

24. Hyperlinks / Links

A Hyperlink or Link is a clickable connection that takes a user from one web page, document or resource to another.

In HTML, the <a> tag is used to create hyperlinks.
